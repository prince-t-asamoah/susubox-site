Notes & TODOs
  • Gold text on white is 2.1:1 (fails AA) — eyebrow is a gold chip with ink text (8.1:1); gold never used as text colour.
  • --color-border (#DDE5E0) is 1.3:1 — too faint for form controls; inputs use proposed --color-border-strong #7C8C84 (3.5:1). Confirm.
  • Error colour, error copy and FAQ section H2 are not in the spec — placeholders shown, marked TODO.
  • #25D366 + white glyph is 2.0:1 — brief-mandated; accessible name via aria-label. Flag to client.
  • All photos are labelled placeholders — source Ghanaian imagery from Unsplash/Pexels; hero 4:5 ≤100 KB, collector 1:1 ≤60 KB.
  • WhatsApp number 233000000000 is a placeholder.
  • Sticky header on mobile & desktop: position sticky, top 0, z-index 40 (under WhatsApp button 50); --header-h 60px mobile / 72px ≥768; solid white + 1px --color-border bottom; no blur.
  • Section links smooth-scroll via CSS (instant with reduced motion); section[id] scroll-margin-top: calc(var(--header-h) + 16px). Mobile menu = full-screen <dialog> (showModal): top bar = header height, ✕ 48×48 in the Menu button's spot; links 1.5rem 700, rows ≥56 (64 used); WhatsApp button + email pinned bottom; 150ms fade; locks page scroll; closes on ✕, Esc, link tap, resize ≥768; floating WhatsApp hidden while open.
  • SAMPLE content (confirm with owner before launch): numbers strip figures (GHS 20 · 7 days · 0) and the Ama testimonial — or remove the testimonial section.
